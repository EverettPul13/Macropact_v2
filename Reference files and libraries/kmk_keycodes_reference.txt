KMK Keycodes (KC) Reference
This file lists all available keycodes in the KC namespace for easy reference
 
THE COMMENT WITH A # NEXT TO IT ARE OTHER WAYS THAT THAT COMMAND CAN BE WRITTEN
anything with a // before it is a description of what that command does 

Modifiers
------------
KC.LEFT_CONTROL  # LCTRL, LCTL    // Left Ctrl key
KC.LEFT_SHIFT    # LSHIFT, LSFT    // Left Shift key
KC.LEFT_ALT      # LALT    // Left Alt key
KC.LEFT_SUPER    # LGUI, LCMD, LWIN    // Left Super/Windows/Command key
KC.RIGHT_CONTROL # RCTRL, RCTL    // Right Ctrl key
KC.RIGHT_SHIFT   # RSHIFT, RSFT    // Right Shift key
KC.RIGHT_ALT     # RALT    // Right Alt key
KC.RIGHT_SUPER   # RGUI, RCMD, RWIN    // Right Super/Windows/Command key
KC.MEH           # LCTL + LALT + LSFT    // Left Ctrl + Alt + Shift combination
KC.HYPER         # LCTL + LALT + LSFT + LGUI, HYPR    // Left Ctrl + Alt + Shift + Super combination

Layer Keys (require arguments)
------------------------------
KC.MO             # Momentary layer    // Activate layer while held
KC.DF             # Default layer    // Set default/base layer
KC.LM             # Layer with modifiers    // Activate layer with modifier keys
KC.LT             # Layer tap    // Activate layer on hold, tap key on press
KC.TG             # Toggle layer    // Toggle layer on/off

KC.TT             # Tap toggle layer    // Toggle layer on double tap, momentary on hold

Mod Tap
---------
KC.MT             # Mod tap    // Hold for modifier, tap for key

Macro & Sequence Commands
-------------------------
KC.MACRO_SLEEP_MS # SLEEP_IN_SEQ    // Add delay in milliseconds between keypresses
KC.send_string("text")    // Type out a string character by character (auto-shifts capitals)
KC.simple_key_sequence((KC.A, KC.B))    // Execute a sequence of keys in order
KC.unicode_string_sequence("✨🎉")    // Send Unicode/emoji directly (auto-converts to codepoints)
KC.unicode_codepoint_sequence(['1f600'])    // Send Unicode by hex codepoint value
KC.compile_unicode_string_sequences({})    // Pre-compile dictionary of Unicode strings into macros
KC.generate_leader_dictionary_seq("abc")    // Convert string into key sequences for LEADER key
